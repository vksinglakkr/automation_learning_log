# 🧪 Lab 2: The Universal Key (Generic Header Auth)

**Objective:** Learn to manually configure an HTTP Request and securely pass an API key using headers.

## 🧠 The Touch Keypad Concept
In Lab 1, we used "Face Unlock" (The AI Agent). It was easy, but what happens when you need to connect to an API like `data.gov.in` or a custom weather service? There are no pre-built agents for every website on the internet!

To unlock these doors, you need to know how to use the **Touch Keypad**. You must manually build the request and securely hand over your secret code.

## 🛠️ What We Built
1. **The HTTP Request Node:** This is the core tool of backend engineering. It allows you to talk to *any* server in the world.
2. **The JSON Body:** Instead of a magic prompt box, we had to format our question exactly how the Groq server expects it: `{"messages": [{"role": "user", "content": "..."}]}`.
3. **The Header Auth Vault:** We used n8n's Generic Header Auth credential. We explicitly defined the lock name (`Authorization`) and the key (`Bearer <your_api_key>`).

## 🎓 The Master-Level Lesson
By using **Generic Header Auth**, your API key is still 100% safe. It is stored securely in n8n's vault and injected at the very last millisecond before the request leaves your computer. 

If you export this workflow and give it to a friend, your API key will **not** be included in the file. You have achieved total control over the API call without sacrificing security!
