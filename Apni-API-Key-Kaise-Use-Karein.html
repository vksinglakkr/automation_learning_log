Apni API Key Kaise Use KareinA Beginner's Complete Guide to data.gov.in API + Auth Concepts

Ye page khaas taur par un students ke liye banaya gaya hai jinhone abhi-abhi data.gov.in par apna account banaya hai aur apni API key generate ki hai. Jab bhi confusion ho, yehi page dobara padh lena.

Part 1 — Apni Key Se Pehla Kaam

1.1 Humara Practice Dataset

Is guide me hum ek real dataset use kar rahe hain, jisse tum khud test kar sako:

Dataset: Year-wise retail inflation rate based on Consumer Price Index-Combined (CPI-C), 2017-18 se 2022-23 tak Resource ID: 352b3616-9d3d-42e5-80af-7d21a2a53fab

Resource ID ko ek tarah se us dataset ka "tracking number" samjho — jaise parcel bhejte waqt ek unique number milta hai, waise hi data.gov.in ke har dataset ka apna alag Resource ID hota hai. Ye number URL me hamesha likha jaata hai.

1.2 Parameters Jo Tum Bhej Sakte Ho

Jab bhi API page dekho, wahan ek chhota table hota hai jisme likha hota hai kaun-kaun se parameters bhej sakte ho:

1.3 Apna Pehla Working URL Banao

Step by step, ek working URL is tarah banta hai:

Step 1 — Base: https://api.data.gov.in/resource/352b3616-9d3d-42e5-80af-7d21a2a53fab
Step 2 — Apni key jodo: ?api-key=TUMHARI_KEY_YAHAN
Step 3 — Format jodo: &format=json
Step 4 — Limit jodo: &limit=10

Final URL (test karne ke liye seedhe browser ke address bar me paste kar sakte ho):

https://api.data.gov.in/resource/352b3616-9d3d-42e5-80af-7d21a2a53fab?api-key=TUMHARI_KEY_YAHAN&format=json&limit=10
Yaad rahe: agar abhi tak apni khud ki key nahi banayi, to isi page par ek sample/demo key already di hoti hai testing ke liye — usse 10 records tak mil jaate hain, par usme rate-limit kam hoti hai. Apna kaam pakka hone ke baad hamesha apni khud ki (My Account se generate ki hui) key use karna.

1.4 Apna Data Filter Karo

Agar sirf ek khaas saal ka data chahiye, to filters[financial_year] jod do:

...&filters[financial_year]=2020-21

Poora URL is tarah dikhega:

https://api.data.gov.in/resource/352b3616-9d3d-42e5-80af-7d21a2a53fab?api-key=TUMHARI_KEY_YAHAN&format=json&limit=10&filters[financial_year]=2020-21

1.5 Isi Key Ko n8n Me Kaise Lagayein

Apne workflow ke HTTP Request node me:

Authentication dropdown me "Generic Credential Type" chuno

Generic Auth Type me "Query Auth" chuno

Naya credential banate waqt: Name box me likho api-key, Value box me apni asli key paste karo

URL field me sirf itna likho: https://api.data.gov.in/resource/352b3616-9d3d-42e5-80af-7d21a2a53fab?format=json&limit=10 (api-key wapas mat likhna — wo credential khud jod dega)

Part 2 — Ab Tak Jo Seekha (Poori Recap)

Ye hissa un sab concepts ka summary hai jo humne pichli classes me seekhe the — Header, Authorization, Bearer, aur humare 7-branch workflow.

2.1 Ek Request Ki Teen Jagah

Har HTTP request me teen jagah hoti hain:

  • URL / Query Parameter — jaise parcel ka bahar wala address label, sabko dikhta hai.
  • Header — parcel ke upar staple kiya hua chhota envelope, jisme alag khaane hote hain.
  • Body — parcel ke andar ka asli saaman.

2.2 "Authorization" Header

Header ke andar tum koi bhi naam likh sakte ho (custom header bhi bana sakte ho, jaise x-api-key). Lekin "Authorization" ek pehle se tay standard naam hai — har server, browser aur security tool ko pata hai ki permission ka proof yahin dhoondhna hai. Isliye zyaadatar companies (Groq, OpenAI, GitHub) yehi naam use karti hain — par data.gov.in nahi karta, wo sirf query parameter accept karta hai.

2.3 "Bearer" Ka Matlab

Authorization header ki value ke andar aksar ek "scheme word" hota hai jo bataata hai key ko kaise padhna hai. Bearer ka matlab: bus-ticket jaisa — jiske paas token hai, wahi allowed hai, extra ID check nahi.

Scheme wordMatlabExample
Bearerbas token dikhao, koi extra check nahiAuthorization: Bearer sk-abc123
Basicusername:password ko base64 karke bhejnaAuthorization: Basic dXNlcjpwYXNz
(kuch nahi)seedha raw key, koi scheme word nahix-api-key: abc123

2.4 Humara 7-Branch Workflow — Final Comparison

#TareekaAuthentication dropdownKey kahan gayiResult
1HardcodedNoneURL me seedhe type kichalta hai (unsafe)
2Query AuthGeneric → Query AuthURL me, par chhupi huichalta hai
3Header AuthGeneric → Header AuthHeader meFAIL hota hai
4Bearer AuthGeneric → Bearer AuthHeader me (Bearer style)FAIL hota hai
5Code-Built QueryGeneric → Query AuthURL me, Code node se banayichalta hai
6Config-DrivenGeneric → Query AuthURL me, Set node se aayichalta hai
7Static (typed-in)NoneURL me, form se aayichalta hai (kam secure)
Pattern yaad rakho: jo bhi tareeka query parameter (URL) me key bhejta hai, wo chalta hai. Jo header ya Bearer me bhejta hai, wo data.gov.in ke liye fail hota hai — kyunki data.gov.in sirf URL hi padhta hai.

2.5 Koi Bhi Naya API Mile To — 5 Sawal

Key kahan jaati hai — URL me, header me, ya body me?

Agar header me, header ka naam kya hai — Authorization ya kuch custom?

Agar Authorization hai, koi scheme word (Bearer/Basic) chahiye ya sirf raw key?

Key ka format kya hai — plain text, base64, ya JWT jaisa token?

Har request ke saath key bhejni hai, ya sirf ek baar login karke session milta hai?
