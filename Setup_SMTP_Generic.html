📤 Kisi Bhi Email Service Ka SMTP Kaise Set KareinOutlook, Yahoo, ya koi bhi custom mail server

Agar Gmail ke alawa Outlook, Yahoo, ya company ka apna mail server use karna ho, to n8n ko manually SMTP settings deni padti hain — host, port, username, password।

Common Providers Ki SMTP Settings

ProviderHostPortSecurity
Gmailsmtp.gmail.com587TLS (App Password chahiye — pehli guide dekho)

Yahoo Mailsmtp.mail.yahoo.com587 ya 465TLS / SSL

Steps

  1. Apne email provider ka SMTP host/port upar table se, ya unki official docs se nikaalo
  2. n8n ke SMTP credential me: Host, Port, User (poora email address), Password daalo
  3. Gmail ke liye Password wale box me apna 16-digit App Password hi daalo, normal password nahi
  4. SSL/TLS wala toggle ON karo
  5. Test karne ke liye ek chhota "Send Email" node banao aur khud ko ek test email bhejo
Port confusion: Port 587 aur 465 dono email ke liye use hote hain, par alag encryption ke saath (587 = STARTTLS, 465 = SSL). Agar 587 kaam na kare (kai baar office/college WiFi isse block kar deta hai), to 465 try karo।
