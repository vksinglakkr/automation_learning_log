☁️ Google Sheets Ke Liye Cloud Credential Kaise BanayeinOAuth Client — Google Sheets se judne wale har project ke liye

n8n ko Google Sheets padhne/likhne ke liye ek OAuth credential chahiye, jo Google Cloud Console se banta hai — Gmail App Password se alag cheez hai, ye credential seedha Google Sheets/Drive API ko access deta hai।

Steps

  1. console.cloud.google.com par jao, naya project banao (ya koi existing project use karo)
  2. "APIs & Services" → "Library" me jao, search karo "Google Sheets API", aur Enable par click karo
  3. Waise hi "Google Drive API" bhi enable kar do (n8n ko dono chahiye hote hain)
  4. "Credentials" tab me jao, "Create Credentials" → "OAuth client ID" chuno
  5. Agar pehli baar kar rahe ho to pehle "OAuth consent screen" setup karne ko kahega — "External" chuno, apna naam/email bhar do
  6. Application type me "Web application" chuno
  7. n8n ke Google Sheets credential screen par ek "OAuth Redirect URL" already likha milega — usi ko copy karke yahan "Authorized redirect URIs" me paste karo
  8. Client ID aur Client Secret milega — dono copy karke n8n ke credential me paste karo
  9. n8n me "Sign in with Google" par click karke apna Google account connect karo
Testing mode ka jhol: Agar OAuth consent screen "Testing" mode me hai (default hota hai), to sirf wahi Google accounts login kar sakte hain jinhe tumne "Test users" me add kiya ho। Apna khud ka email zaroor add karo।
