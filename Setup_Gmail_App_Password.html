🔑 Gmail App Password Kaise Banayein16-digit App Password — Gmail se judne wale har project ke liye

Google ne 2022 se apna normal Gmail password kisi bhi third-party app (jaise n8n) ko seedha use karne dena band kar diya — security ke liye. Isliye n8n ko ek special 16-digit "App Password" chahiye, apna roz wala Gmail password nahi।

Zaroori: App Password tabhi milta hai jab tumhare Google account par 2-Step Verification (2FA) pehle se ON ho। Bina isske ye option dikhega hi nahi।

Steps

  1. myaccount.google.com par jao, apne Google account me login karo
  2. Left menu me "Security" par click karo
  3. "2-Step Verification" ON karo agar pehle se nahi hai — apna mobile number verify karke
  4. Wapas Security page par aao, neeche "App passwords" dhoondo (ya seedha myaccount.google.com/apppasswords par jao)
  5. App ka koi bhi naam likho (jaise "n8n workflow"), "Create" par click karo
  6. Google ek 16-digit code dikhayega, jaise:
abcd efgh ijkl mnop
  1. Yehi code copy karlo — spaces ke saath ya bina, dono chalta hai
  2. n8n ke Gmail/SMTP credential me: Email = apna Gmail address, Password = yehi 16-digit code (apna asli Gmail password nahi)
